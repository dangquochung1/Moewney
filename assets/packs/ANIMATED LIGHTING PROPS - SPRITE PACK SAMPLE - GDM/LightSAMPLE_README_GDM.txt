ANIMATED LIGHTS: PROP SPRITE PACK [SAMPLE]
README
================================================================
 
OVERVIEW
----------------------------------------------------------------
This sample pack contains 8 animated light props across two
resolutions (16x16 and 32x32)
 
Included prop types per resolution size:
  - Candles      (1 design)
  - Lanterns     (1 design)
  - Torches      (1 design)
  - Streetlamps  (1 design)
 
WHAT'S INCLUDED
----------------------------------------------------------------
  - Sprite sheets (PNG) for each light type
  - JSON files for each light type, separated by color (Aseprite format, metadata for frames/animations)



 
FILE STRUCTURE
----------------------------------------------------------------
The download is organized as follows:
 
Resolution (16x16 or 32x32)
	Light Type (Candles, Lanterns, Torches, Streetlamps)
		PNG Sprite Sheet (ex. "Lantern_Sample_16.png")
		JSON File (ex. "Lantern_Sample_16.json")

		
 
ASSET SPECIFICATIONS
----------------------------------------------------------------
Resolutions:    16x16 px and 32x32 px
Format:         PNG spritesheets + JSON data files
Source:         Aseprite (.aseprite)
 
Usage Note:
Sprite sheets can be used in any engine that supports sprite slicing.
JSON files are provided as Aseprite metadata and may require custom scripts or tools for import.

Animations included per sprite:
  1. Light Up   -- the fire ignition sequence (first row)
  2. Fire Loop  -- the idle burning loop (second row)
  3. Fire Out   -- the fire extinguish sequence (third row)
